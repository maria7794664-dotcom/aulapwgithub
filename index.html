✦ Introdução

Na programação, é muito importante conseguir organizar os arquivos e acompanhar as mudanças realizadas em um projeto. Para isso, existem ferramentas como o Git e o GitHub.

Nesta atividade de Lógica de Programação, vamos conhecer essas duas ferramentas e entender como elas podem ajudar no desenvolvimento de projetos.

✦ O que é Git?

O Git é um sistema de controle de versões utilizado para acompanhar as alterações realizadas nos arquivos de um projeto.

Ele permite guardar um histórico das mudanças. Dessa forma, podemos acompanhar o desenvolvimento do projeto e até voltar para versões anteriores quando necessário.

✎ Controle de versões

Registra as alterações realizadas durante o desenvolvimento de um projeto.

✦ Histórico

Permite consultar o que foi alterado ao longo do tempo.

✦ O que é GitHub?

O GitHub é uma plataforma online utilizada para armazenar, compartilhar e colaborar em projetos de programação.

Ele utiliza o Git e permite que os projetos sejam armazenados na internet, facilitando o trabalho entre diferentes pessoas.

O GitHub pode ser utilizado para:

  • Guardar projetos online;
  • Compartilhar códigos;
  • Trabalhar em equipe;
  • Acompanhar alterações;
  • Publicar sites com o GitHub Pages.

✦ Git x GitHub

Git

É um sistema de controle de versões que acompanha as alterações realizadas em um projeto.

GitHub

É uma plataforma online que permite armazenar, compartilhar e colaborar em projetos que utilizam Git.

✦ Conclusão

Aprender sobre Git e GitHub é importante para quem está começando na programação, pois essas ferramentas ajudam a organizar, controlar e compartilhar projetos.

O Git trabalha com o controle das versões, enquanto o GitHub facilita o armazenamento e o compartilhamento dos projetos pela internet.
